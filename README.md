Hopeful Horizons Therapeutics Website

This project is a fully responsive, multi‑page website built for Hopeful Horizons Therapeutics, LLC, a mental health therapy practice based in Ashland, Kentucky. 
The site is designed to feel warm, grounded, and welcoming — reflecting the practice's mission of providing compassionate, trauma‑informed care.

The project includes four pages:

- Home
- About
- Services
- Contact Us

Each page is styled with a consistent design system using custom CSS variables, soft color palettes, and clean typography.

*Design Goals*

The visual identity focuses on:

- Calming, therapeutic colors (sage-calm, peach-glow, soft-mauve)
- Readable, modern typography using Poppins
- Gentle animations for subtle polish
- Consistent spacing and layout rhythm
- Warm, human-centered language

The goal was to create a site that feels safe, approachable, and professional — ideal for a therapy practice.

*Tech Stack*

- Blazor Web App (.NET 8)

- Razor components

- HTML5

- CSS3 (custom design system)

- Bootstrap (light usage)

- Google Maps Embed


*Page Structure*

Home
- Hero section with logo and tagline
- Introductory card with supportive messaging
- CTA linking to the About page

About
- Therapist biography
- Credentials and background
- Specialties and therapeutic approaches
- CTA linking to Services

Services
- Sliding fee scale table
- Payment policy
- Accepted insurance list
- CTA linking to Contact

Contact Us
- Contact information
- Office location
- Embedded Google Map
- Phone and email links

*Responsive Design*

The site includes mobile‑first optimizations:
- Stacked navigation
- Scaled hero logo
- Adjusted typography
- Flexible card layouts
- Responsive map embed

The layout remains clean and readable across devices.

*Code Quality*

This project emphasizes:

- Clean, readable HTML
- Organized CSS with clear sectioning
- Reusable classes and variables
- Minimal inline styling
- Consistent naming conventions
- Accessible alt text and link semantics

*Future Enhancements*

Potential next steps:
- Add a message box on Contact Us Page
- Add appointment scheduling integration
- Expand accessibility features
